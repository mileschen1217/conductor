# Claude Code adapter

Binding of dispatch primitives and capability tiers: `binding.md`. The
skill entry point is `SKILL.md` beside it.

Verification records (`verified-run:` lines — one per commander×topology
cell that completed a protocol run) are operator-local: they live with the
benchmark ledger, whose rows reference local artifacts, and do not ship.
Convention and evidence rules: `benchmark/protocol.md § Verification
record`. A verification record is not a capability claim.
